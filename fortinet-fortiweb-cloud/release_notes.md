#### Following enhancements have been made to the Fortinet FortiAppSec Cloud Connector in version 2.0.0:

- The connector name has been renamed from Fortinet FortiWeb Cloud to Fortinet FortiAppSec Cloud.
- The connector logo has been updated.
- The previous version of the APIs were deprecated and hence replaced with updated versions.
- Added a new parameter Forward in the action Get Applications List.
- Added a new action - Execute an API Request
